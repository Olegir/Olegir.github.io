# Money Tracker · Smart Scan 2.0 (тестова версія)

## Запуск
1. Розпакуйте ZIP на Робочий стіл.
2. У Terminal: `cd ~/Desktop/money-tracker-smart-scan-2 && python3 -m http.server 8003`
3. У Safari: http://localhost:8003

## Що нового
- Режим «Автоматично», «Товарний чек», «Квитанція / оплата».
- Квитанції зберігаються як одна витрата, а товарні чеки — як витрата з переліком товарів.
- Редагування суми, категорії й опису перед збереженням.
- Евристичне знаходження сум на кшталт «СУМА ДО СПЛАТИ: 85.00».

## Обмеження
- Це НЕ хмарний AI: OCR виконується локально в браузері бібліотекою Tesseract.js, яка завантажується через інтернет.
- Розпізнавання може помилятися; обов'язково перевіряйте суму, дату й категорію.
- Жодного API-ключа або сервера для AI тут немає.
- Дані зберігаються локально в браузері; зробіть резервну копію JSON.
- Не публікуйте фотографії квитанцій із персональними даними.
